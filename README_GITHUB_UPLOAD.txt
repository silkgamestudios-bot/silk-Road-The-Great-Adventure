SUBIR MEDIANTE LA WEB DE GITHUB
1. Descarga y descomprime este ZIP en tu computadora.
2. Abre el repositorio de GitHub.
3. En Add file > Upload files, arrastra el contenido descomprimido (no el ZIP como único archivo).
4. Esta versión contiene menos de 100 archivos, así que cabe en una sola tanda de carga web por cantidad de archivos.
5. Haz Commit changes.
